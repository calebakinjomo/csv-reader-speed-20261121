A fast drop-in for csv-reader 1.0.0: it reads broken CSV files and returns byte-identical answers, but with a tight single-pass scanner (bulk indexOf/slice field extraction, no per-character concatenation) that runs several times faster than the reference.

## Run it

```sh
node main.ts
```
